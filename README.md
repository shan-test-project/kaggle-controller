# Kaggle Controller

**Your Kaggle workspace, redesigned for Android.**

A production-quality mobile control center for Kaggle — not just an API wrapper, but a complete mobile IDE experience for notebooks, datasets, models, competitions, schedules, automation, and developer productivity.

## APK Info

- **App Name:** Kaggle Controller
- **Package:** `com.kaggle.controller`
- **Version:** `1.0.0001`
- **Target SDK:** 34
- **Min SDK:** 24

## Build Strategy

**Never build locally.** The APK is built exclusively through GitHub Actions to ensure consistent, reproducible, signed releases.

- **Forever-use debug signing:** Every build uses the same `debug.keystore` (`kaggle-debug` alias / `kaggle-debug` password) so all releases share one consistent signing identity.
- **GitHub Actions workflow:** `.github/workflows/build-apk.yml` handles the full build pipeline, artifact upload, and APK verification.

## Key Features (Implemented & Planned)

Per the full build guide (`Writing.txt`):

- Home Dashboard with quick actions and live stats
- Universal Kaggle Search (notebooks, datasets, models, competitions)
- Powerful Notebook Manager with favorites, drafts, local changes
- Mobile Notebook Editor with syntax highlighting and keyboard toolbar
- Import / Export (.ipynb, .py, .r, .rmd)
- Execution Control Center with live run monitoring
- Dataset, Model, and Competition browsers
- Automation Rules and Workflow Builder
- AI Assistant (optional, user-configured API keys)
- Error Copilot for failed runs
- Offline mode, sync engine, and smart collections
- Professional dark navy + electric cyan theme (Material 3)

## Security

- No hardcoded API keys or OAuth secrets
- Secure Android storage (DataStore + Security Crypto)
- Minimum OAuth scopes requested progressively
- Never send notebook content to remote AI without explicit user action
- Rate-limit protection with exponential backoff

## Testing

- Unit tests for repositories, ViewModels, and serialization
- Mock Kaggle APIs
- Compose UI tests
- Real Kaggle credentials never required by automated tests

## Running the App

1. Clone the repository
2. Open `kaggle-controller/` in Android Studio (Arctic Fox or newer)
3. Ensure `debug.keystore` exists (generated by `generate-debug-keystore.sh` or GitHub Actions)
4. **Do not build the APK locally.** Push to trigger the GitHub Actions build.

## Requirements

- Android Studio with Kotlin 1.9+ and Compose 1.6+
- Android SDK 34
- Java 17

## Known Limitations

When a Kaggle feature is available on the website but not through the public API, the app clearly shows **"Open in Kaggle"** using Android Custom Tabs rather than inventing unsupported endpoints.
